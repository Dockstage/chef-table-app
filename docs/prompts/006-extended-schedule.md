# Промпт 006 — расширенный период расписания

## Отправленный промпт

> Исправь несоответствие R-027: семь дней остаются периодом по умолчанию, но пользователь должен расширять расписание до 14 или 30 дней. Передавай фактические `from/to` в API и не теряй карточки прошлых или отменённых броней при фильтрации расписания.

## Результат и проверка

Добавлен переключатель периода, чистая функция диапазона, фильтрация mock API и endpoint отдельного класса для связанных с бронями архивных данных.
