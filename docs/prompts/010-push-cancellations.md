# Промпт 010 — push при отмене студией

## Отправленный промпт

> Реализуй обязательное уточнение R-008/R-013 для клиентского приложения: пользователь явно включает уведомления, приложение получает нативный device token, регистрирует его в API и слушает событие `class_cancelled`. После события обнови брони, открой раздел записей и покажи понятное сообщение. Web должен корректно сообщать, что push доступен только в Android/iOS. Не запрашивай разрешение автоматически при старте.

## Результат и проверка

Добавлены Expo Notifications, endpoint регистрации токена, UI-состояния разрешения, listener отмены и тесты маршрутизации события и API-запроса.
