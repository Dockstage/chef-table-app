## Рабочий промпт

Начни CL-09 с безопасного выбора источника данных. Убери неявный переход на `MockStudioApi`: режимы HTTP и demo должны задаваться явно. Для HTTP потребуй `EXPO_PUBLIC_API_BASE_URL` и локальный development Bearer token, подключи token provider к `HttpStudioApi`, а при неполной конфигурации заверши запуск понятной ошибкой. Зафиксируй явный mock-режим в CI, добавь тесты выбора адаптера и авторизации, синхронизируй инструкции, архитектуру, трассировку и план. Не выполняй полный e2e до отдельного интеграционного шага.
