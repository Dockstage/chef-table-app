# Промпт 003 — реализация клиента

## Отправленный промпт

> Реализуй Expo/React Native/TypeScript клиент «Шеф-стол» по требованиям R-001–R-012. Нужен выразительный mobile-first интерфейс без внешних изображений: расписание на 7 дней с фильтром уровня и empty state; карточка и форма бронирования с выбором своего/прокатного набора, аллергиями и итоговой ценой; раздел активных и прошлых броней с отменой по правилу 12 часов и причиной отмены студией; оценка шефа после посещения. Используй асинхронный MockStudioApi, чистые domain policies, деньги в копейках. Сохрани обработку loading и предметных API-ошибок.

## Результат и проверка

Реализованы четыре пользовательские функции и три состояния расписания. Код сверяется TypeScript-компилятором; сценарии дополнительно проверяются в web-preview и тестами.
