# Промпт 002 — архитектура и данные

## Отправленный промпт

> Спроектируй клиентское мобильное приложение кулинарной студии на Expo/React Native/TypeScript. Backend уже существует как black box. Нужны слои, поток зависимостей, управление состояниями loading/empty/error, модель данных с инвариантами, OpenAPI-контракт для расписания, бронирования, отмены и оценки, а также sequence diagram конкурентного бронирования. Деньги храни в копейках, даты — ISO 8601. Не переноси серверные гарантии на клиент.

## Результат и проверка

Созданы архитектурный план, ER-модель, OpenAPI 3.1 и sequence diagrams. Вручную проверено, что атомарность бронирования остаётся ответственностью backend, а mock реализует контракт только для демонстрации.
