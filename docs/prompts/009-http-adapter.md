# Промпт 009 — HTTP-адаптер существующего backend

## Отправленный промпт

> Устрани риск, что проект содержит только mock. Реализуй `HttpStudioApi` по OpenAPI-контракту: расписание с `from/to`, карточка класса, брони, создание с `Idempotency-Key`, отмена и отзыв. Корректно преобразуй problem response в доменную ошибку. Оставь mock как демо fallback и переключай реализацию через `EXPO_PUBLIC_API_BASE_URL`. Добавь контрактные тесты без реальной сети.

## Результат и проверка

Добавлены HTTP-адаптер, фабрика выбора окружения, `.env.example` и тесты URL, идемпотентности и предметной ошибки.
