# PROMPT-064 — Сокращённый scope тестирования

## Запрос пользователя

> Короче, я узнал, что не обязательно прям так жёстко делать часть тестирования. Можешь просто самые какие-то важные пункты выделить и всё. Потом сделаем отчёт, сделаем практику и закончим

## Рабочий промпт

> Сократи обязательный тестовый план до минимального учебного scope, не удаляя результаты полного аудита. Оставь четыре видимых шага: актуализация test cases/BUG, один финальный автоматический регресс, ключевой ручной web-smoke с актуальными evidence и итоговый отчёт. JSON/TMS, большая component-suite, k6, coverage threshold, Figma и native проверки перенеси в свёрнутый необязательный backlog и не выдавай за выполненные. Синхронизируй audit/alignment, создай TASK/PROMPT и focused commit.

После подготовки пользователь отдельно указал не коммитить это изменение; локальные файлы оставлены без commit.
