# Промпт 001 — требования к MVP

## Цель

Получить проверяемые требования из сырого брифа заказчика.

## Отправленный промпт

> Ты — системный аналитик мобильных продуктов. На основе брифа кулинарной студии выдели MVP только для роли клиента. Существующий backend и админка находятся вне скоупа, backend является источником истины и предотвращает двойные брони. Подготовь уточняющие вопросы, допущения, функциональные и нефункциональные требования с ID, user stories с критериями приёмки, основные и альтернативные сценарии, список вне MVP и измеримые критерии успеха. Не придумывай функции, которые противоречат ограничениям брифа.

## Результат и проверка

Результат декомпозирован в `docs/01-analysis/`. Требования вручную сверены с исходным брифом: сохранены роль клиента, горизонт 7 дней, black-box backend и специальный статус отмены студией.
