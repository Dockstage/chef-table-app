# PROMPT-017 — User Stories и Use Cases

## Запрос пользователя

> Давай следующий шаг.

Контекстом служил согласованный следующий шаг: усилить User Stories и Use Cases после разделения BR/FR/NFR; все изменения коммитить.

## Рабочий промпт

Переработай существующие User Stories в формате Card / Conversation / Confirmation. Для каждой укажи MoSCoW-приоритет, источник, связи с BR/FR/NFR и проверяемые Given/When/Then-критерии; выполни честную INVEST-проверку. Для каждого Use Case укажи цель, акторов, заинтересованные стороны, триггер, предусловия, успешное постусловие, минимальную гарантию, основной поток, альтернативы и исключения. Отдельно покрой offline/timeout/retry, конфликт места и проката, дедлайн отмены, отказ push-разрешения и platform differences. Не добавляй неподтверждённые production-возможности.
