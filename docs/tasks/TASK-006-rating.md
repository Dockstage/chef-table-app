# TASK-006 — Оценка шефа

## Цель

Собрать обратную связь только от реально посетивших класс клиентов.

## Требования

R-010; US-05; UC-03.

## Промпты

- `docs/prompts/003-implementation.md` — первоначальная реализация.
- `docs/prompts/008-review-comment.md` — комментарий к отзыву.
- `docs/prompts/011-accessibility-and-ux.md` — accessibility оценки.

## Реализовано

- модальное окно оценки 1–5;
- необязательный комментарий до 500 символов;
- доступность только для статуса `attended`;
- запрет повторной оценки;
- отображение сохранённой оценки.

## Ручная проверка

- [x] Без выбора звезды отправка недоступна.
- [x] После отправки кнопка исчезает.
- [x] Оценка показывается в карточке истории.
- [x] Комментарий сохраняется и показывается в карточке истории.
