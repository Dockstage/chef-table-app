# TASK-011 — Push-уведомления об отмене студией

## Цель

Сразу предупредить клиента об отмене класса и показать причину в актуальной истории.

## Требования

Уточнение брифа R-008; R-013.

## Промпт

`docs/prompts/010-push-cancellations.md`.

## Реализовано

- явное включение уведомлений в профиле;
- запрос системного разрешения только по действию пользователя;
- получение нативного APNs/FCM-токена;
- регистрация токена в `/push-tokens`;
- обработка `class_cancelled` с обновлением броней;
- обработка foreground-доставки, нажатия по уведомлению и холодного запуска;
- понятный web fallback.

## Проверка

- [x] Web не вызывает неподдерживаемый native API.
- [x] HTTP-тест проверяет endpoint и payload токена.
- [x] Unit-тест отличает отмену класса от постороннего уведомления.
- [x] Unit-тесты проверяют foreground, открытие уведомления, холодный запуск и очистку listeners.
- [ ] Доставка реального push проверяется на физическом Android/iOS с настроенным backend-провайдером.
