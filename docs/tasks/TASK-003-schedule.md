# TASK-003 — Расписание и фильтры

## Цель

Дать клиенту быстрый выбор класса на ближайшую неделю.

## Требования

R-001, R-002, R-003, R-011, R-012; US-01 и US-02.

## Промпт

`docs/prompts/003-implementation.md`.

## Реализовано

- горизонт 7 дней;
- фильтр «Все / Новичкам / С опытом»;
- карточки со временем, шефом, ценой и остатком;
- empty и loading states;
- подробности класса с меню и адресом.

## Ручная проверка

- [ ] Переключение каждого дня.
- [ ] Фильтр уровня не сбрасывает дату.
- [ ] На пустой комбинации появляется empty state.
- [ ] Карточка открывает правильный класс.
