Создать единый технический источник для реализации всех клиентских экранов и общих правил на основе стабильных дизайн-брифов и API-контракта.

## Источники

- лекционный промпт и шаблоны mobile app spec;
- BR/FR/NFR, User Stories и Use Cases;
- `03-design-brief`;
- data model, sequences и OpenAPI 1.1;
- текущий Expo UI только как baseline, не как источник целевого поведения.

## Промпт

`docs/prompts/020-mobile-app-spec.md`.

## Выполнено

- подготовлены отдельные ТЗ для 3 экранов, bottom sheet, modal и dialog;

- мобильное ТЗ связано с дизайн-реестром, а чек-лист обновлён.
