# TASK-005 — Мои классы и отмена

## Цель

Показать клиенту состояние его планов и дать безопасно освободить место.

## Требования

R-007–R-009; US-04; UC-02.

## Промпт

`docs/prompts/003-implementation.md`.

## Реализовано

- предстоящие и история;
- четыре статуса брони;
- причина отмены студией;
- подтверждение отмены клиентом;
- правило дедлайна 12 часов и возврат места.

## Ручная проверка

- [x] Фильтры разделяют будущие и прошлые брони.
- [x] Отмена студией остаётся в списке с причиной.
- [x] После клиентской отмены API возвращает статус истории.
- [x] Поздняя отмена недоступна.
