# BUG-002 — Неверная ошибка для отменённого класса

## Симптом

При попытке записаться на отменённый студией класс Mock API отвечает `SLOT_FULL`, потому что раньше проверяет нулевой остаток. Клиент не может объяснить настоящую причину.

## Требования

R-008, US-03: повторная запись запрещена, API возвращает `SLOT_CANCELLED`.

## Шаги воспроизведения

1. Найти класс со статусом `cancelled`.
2. Вызвать `createBooking`.
3. Проверить `StudioApiError.code`.

Факт: `SLOT_FULL`. Ожидание: `SLOT_CANCELLED`.

## Промпт

> Проверь порядок валидаций createBooking для отменённого класса. Сначала должна проверяться бизнес-причина недоступности, затем остаток. Добавь регрессионный тест на точный код `SLOT_CANCELLED` и исправь порядок без изменения публичного контракта.
