# BUG-003 — Отмена студией показывалась в предстоящих

## Симптом

Бронь со статусом `cancelled_by_studio` отображалась во вкладке «Предстоящие», хотя занятие больше не состоится.

## Требование

R-008 и US-04: отменённая студией бронь не удаляется, а сохраняется в истории с причиной.

## Промпт

`docs/prompts/007-cancelled-booking-history.md`.

## Исправление

Статус исключён из предстоящих и добавлен в историю. Правило вынесено в `filterBookings`.

## Проверка

- [x] В «Предстоящих» отменённой брони нет.
- [x] В «Истории» бронь присутствует со статусом и причиной.
- [x] Регрессионный тест фиксирует оба условия.

## Commit

Заполняется после фиксации исправления.
