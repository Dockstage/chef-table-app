# TASK-010 — Реальный HTTP-адаптер

## Цель

Сделать клиент готовым к существующему backend, не теряя автономный demo-режим.

## Требования

Граница серверной интеграции R-004 и канонический API-контракт R-015.

## Промпт

`docs/prompts/009-http-adapter.md`.

## Реализовано

- `HttpStudioApi` для всех пользовательских сценариев;
- `Idempotency-Key` для создания брони;
- предметное преобразование ошибок;
- выбор HTTP/mock через `EXPO_PUBLIC_API_BASE_URL`;
- контрактные тесты с подменённым `fetch`.

## Проверка

- [x] Диапазон и уровень сериализуются в query string.
- [x] Создание брони содержит уникальный ключ.
- [x] Ошибка backend сохраняет код и понятное сообщение.
- [x] Без env приложение запускается на mock.
