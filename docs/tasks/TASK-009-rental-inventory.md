# TASK-009 — Свободный прокатный фонд

## Цель

Не позволять клиенту заказать отсутствующий рабочий набор.

## Требования

Уточнение брифа R-015; `docs/01-analysis/mvp-requirements.md`.

## Промпт

`docs/prompts/005-rental-inventory.md`.

## Реализовано

- остаток прокатных наборов в модели и OpenAPI;
- отображение остатка и отключение недоступного варианта;
- ошибка `RENTAL_UNAVAILABLE`;
- уменьшение остатка при записи и возврат после отмены.

## Проверка

- [x] При нулевом остатке вариант проката недоступен.
- [x] API отклоняет прямой запрос проката при нулевом остатке.
- [x] После отмены прокатный набор возвращается в фонд.
