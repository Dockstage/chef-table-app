# TASK-008 — Расписание за пределами недели

## Цель

Сохранить недельный период по умолчанию и дать клиенту открыть более поздние даты.

## Требования

Уточнение брифа R-027; R-001 и R-002.

## Промпт

`docs/prompts/006-extended-schedule.md`.

## Реализовано

- периоды 7, 14 и 30 дней;
- запрос API с `from/to`;
- тестовые классы за пределами первой недели;
- загрузка отдельных классов для истории броней.

## Проверка

- [x] Начальное значение — 7 дней.
- [x] На 14 днях доступен класс десятого дня.
- [x] На 30 днях доступен класс шестнадцатого дня.
- [x] История броней не теряет карточки классов.

## Commit

Заполняется после фиксации реализации.
