# Тест-кейсы MVP

Дата составления: 19.09.2026; актуализировано 28.09.2026. Среда: Expo SDK 57, web-preview, Vitest, FastAPI и PostgreSQL.

Обозначения в столбце «Фактическое покрытие»: `auto` означает существующую автоматическую проверку указанного слоя; `manual` — ручную проверку. Автотест domain/data-логики не считается проверкой отрисованного UI, а тест notification-логики — доказательством доставки через APNs/FCM.

## Регрессионный минимум

Перед каждым релизом вручную выполнить UI-части TC-001, TC-005 и TC-014; автоматизированные TC-007, TC-009, TC-010, TC-012 и TC-013 входят в соответствующие client/backend-наборы. Затем выполнить финальные команды из [`docs/04-testing/coverage-summary.md`](04-testing/coverage-summary.md).
