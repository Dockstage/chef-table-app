## Разработка

| Практика из лекции | Реализация в проекте | Статус |
|---|---|---|
| Декомпозировать работу и сохранять промпты | TASK/BUG-карточки, хронологический реестр промптов и отдельные commits | Выполнено |
| Реализовать клиентские функции | Expo/React Native-клиент, mock и HTTP adapter; реализовано более трёх функций | Выполнено для текущего client baseline |
| Разделить client и backend | Expo-клиент находится в `client/`, FastAPI и БД — в `backend/`, общие документы — в `docs/` | Выполнено |
| Реализовать собственный backend | Созданы FastAPI-каркас, PostgreSQL-схема, миграции, seed и health endpoint | Частично: доменные endpoint ещё не реализованы |
| Обеспечить воспроизводимый запуск | Корневой Docker Compose поднимает PostgreSQL и backend; миграции и seed запускаются отдельными командами | Выполнено для backend-инфраструктуры |
| Соблюдать целевой контракт | OpenAPI готов, но retry, DTO, auth wiring и push validation клиента требуют доработки | Частично |

Expo-приложение отделено в `client/`, но структура ещё не итоговая: `client/App.tsx` требует декомпозиции, доменные endpoint backend не созданы, а `MockStudioApi` остаётся demo/test fallback.

## Осознанные отличия от примера

- В исходном брифе backend считался существующим; собственный FastAPI оформлен отдельным учебным расширением в ADR-001, исходный файл не изменён.
- Figma-макеты не заявляются: до их появления используются текстовые дизайн-брифы и текущий UI как baseline D-008.
- Web служит демонстрационным preview; Android/iOS остаются целевыми платформами, поэтому web-push не обещается.
- Наличие ТЗ или OpenAPI не считается доказательством реализации: такие разрывы помечены как `Частично` или `Не выполнено`.

## Итог

Часть «Анализ» соответствует изученному лекционному процессу и закрыта по документам. В «Разработке» готовы раздельные client/backend, Docker и база; далее нужны доменные endpoint и контрактная проверка. В «Тестировании» ещё требуются полноценные UI, API, интеграционные и конкурентные наборы. Порядок работ зафиксирован в `lecture-gap-checklists.md`.
