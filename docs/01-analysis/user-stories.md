# User stories и критерии приёмки

## US-01 — Просмотр расписания

Как клиент, я хочу видеть доступные классы на ближайшую неделю, чтобы выбрать удобное время.

Критерии:

- по умолчанию отображаются следующие 7 календарных дней;
- отменённые и завершённые классы нельзя забронировать;
- если классов нет, показывается текст «Пока нет доступных классов»;
- фильтр уровня не изменяет выбранную дату.

## US-02 — Детали класса

Как клиент, я хочу изучить меню, уровень, шефа, адрес и условия, чтобы принять решение.

Критерии:

- отображаются программа, блюда, длительность, цена и свободные места;
- цена проката показывается отдельно;
- для последнего места выводится заметное предупреждение.

## US-03 — Бронирование

Как клиент, я хочу записаться и сообщить об аллергиях, чтобы студия подготовилась к моему визиту.

Критерии:

- необходимо выбрать вариант инвентаря;
- поле аллергий ограничено 300 символами;
- итоговая сумма включает прокат;
- успешная бронь появляется в разделе «Мои классы»;
- при `409 SLOT_FULL` UI сообщает, что место уже занято;
- повторная активная бронь отклоняется.

## US-04 — Отмена

Как клиент, я хочу заранее отменить запись, чтобы освободить место.

Критерии:

- до дедлайна UI показывает кнопку отмены;
- менее чем за 12 часов отмена недоступна с объяснением;
- отменённая бронь остаётся в истории;
- отмена студией показывает её причину.

## US-05 — Оценка шефа

Как посетивший класс клиент, я хочу поставить оценку шефу, чтобы помочь студии улучшать качество.

Критерии:

- оценка доступна только после посещённого класса;
- допустимое значение — целое число от 1 до 5;
- одну бронь нельзя оценить повторно;
- после отправки показывается сохранённая оценка.
