# QA-ревью требований

Дата: 26.09.2026. Объект ревью: BR/FR/NFR, US/UC, доменные правила, дизайн-брифы, мобильные ТЗ, OpenAPI, модель данных, матрица трассировки, текущий клиент и тест-кейсы.

## Итог

Блокирующих противоречий внутри целевой аналитики не осталось. Две найденные несогласованности исправлены: Bearer-auth распространён на все сетевые истории согласно OpenAPI, а метрика пути записи получила NFR-012 и TC-025. Правила хранения результата идемпотентного запроса и подсчёта длины текста формализованы решениями D-009 и D-010. Остальные замечания относятся к будущей реализации и проверкам; они уже отражены в матрице и чек-листах.

Статусы: **Исправлено** — документы синхронизированы; **Принято** — существующая граница подтверждена; **Открыто** — требуется работа на этапе разработки или тестирования.

## Реестр замечаний

| ID | Категория | Наблюдение и риск | Решение / маршрут | Статус |
|---|---|---|---|---|
| QA-001 | CONFLICT | OpenAPI защищает все 7 операций, но US-01/US-02 и матрица исключали чтение классов из FR-015 | Добавлены FR-015/NFR-011 в истории просмотра; матрица указывает все операции | Исправлено |
| QA-002 | COVERAGE | Метрика BR-001 «не более пяти действий» не имела требования и теста | Добавлены NFR-012 и TC-025; определено, что считается действием | Исправлено |
| QA-003 | DECOMP | Не были определены срок жизни идемпотентного результата и основа `requestHash` | D-009: хранение до сброса учебной БД; SHA-256 канонического валидированного payload | Исправлено |
| QA-004 | REQUEST | Профиль выглядит как настройка push, но API поддерживает только регистрацию, без logout/отзыва токена | Для MVP это действие подключения; production opt-out остаётся в OQ-004 | Принято |
| QA-005 | CONFLICT | LOGIC-001 требует московскую дату, а текущий `getScheduleQuery()` использует timezone устройства | Не менять требование; исправить клиент на этапе разработки и добавить timezone-тесты | Открыто |
| QA-006 | FORMAT | OpenAPI требует явные nullable-поля, текущие TypeScript DTO используют optional; `ApiErrorCode` неполон | Синхронизировать DTO/error union с OpenAPI перед backend-интеграцией | Открыто |
| QA-007 | COVERAGE | Initial Error, Stale и независимый refresh после mutation описаны, но component/scenario-тестов нет | Добавить проверки состояний и не считать unit domain-тест эквивалентом UI-сценария | Открыто |
| QA-008 | COVERAGE | NFR-001, NFR-003, NFR-006, NFR-008 и NFR-011 не имеют воспроизводимого доказательства | Закрывать отдельными performance, accessibility, log-capture, schema и auth проверками | Открыто |
| QA-009 | LAYOUT | Web 360×800 проверен, но keyboard/safe-area и длинный контент BS-001/MDL-001 на Android/iOS не проверены | Добавить native layout-набор на обеих платформах | Открыто |
| QA-010 | DECOMP | Отмена класса и отметка посещения нужны сценарию, но публичная админка запрещена scope | Использовать внутренние backend services и seed/test fixtures; не добавлять client/admin endpoints | Принято |
| QA-011 | COVERAGE | TC с пометкой UI/auto не означает наличие component/e2e-теста; текущие 24 автотеста проверяют domain/data/notifications | Развести unit/component/scenario/layout suites и отчётность на этапе тестирования | Открыто |
| QA-012 | FORMAT | Лимиты 300/500 должны одинаково считаться Python и TypeScript, особенно для emoji | D-010: сервер — источник истины; клиент считает Unicode code points, не UTF-16 units | Исправлено в требованиях; код открыт |

## Импакт-анализ

| Изменение | Затрагиваемые области | Обязательная регрессия |
|---|---|---|
| Стабильный retry брони | BS-001, LOGIC-003, `StudioApi`, HTTP/mock, FastAPI service, `IdempotencyRecord` | lost `201`, double tap, новый/старый payload, 20 конкурентных запросов |
| Обязательный Bearer | Все 7 operationId, auth config, HTTP adapter, FastAPI dependency | valid token, missing/invalid token, отсутствие токена в логах/Git |
| Московская дата | SCR-001, LOGIC-001/004, client policies, backend time policy | границы суток/месяца, устройство в другой timezone, ровно 12 часов |
| Разделение mutation/refresh | BS-001, DLG-001, MDL-001, SCR-002, LOGIC-007 | success + refresh timeout, сохранение returned DTO, отсутствие ложного повтора |
| Nullable/error DTO | OpenAPI, Pydantic, TypeScript types, adapters, UI fallbacks | schema compatibility, null/missing, каждый Problem code |
| External studio event | backend services, booking transaction, push outbox/adapter, fixtures | все confirmed → cancelled, reason snapshot, одна отправка/без дублей |

## Platform differences

| Область | Android/iOS | Web-preview | Что проверить |
|---|---|---|---|
| Push | Permission, native token, foreground/tap/cold start | `unsupported`, API не вызывается | Реальные устройства/эмуляторы и отказ разрешения |
| Back/overlay | Системный Back закрывает верхний слой | Browser/overlay close | Данные формы не теряются при ошибке запроса |
| Подтверждение отмены | Native `Alert` | Browser confirm | Одинаковое destructive действие и отсутствие двойного запроса |
| Keyboard/safe area | Возможны перекрытие CTA и inset | Проверен только viewport | BS-001/MDL-001, длинный текст, 360×800 |
| Даты | Не зависят от timezone устройства | То же правило | `Europe/Moscow` на устройствах с другой зоной |

## Вопросы аналитику

Новых блокирующих вопросов для учебного MVP нет. Не меняя текущий scope, перед production остаётся согласовать `OQ-001`–`OQ-009`: production-auth, юридическую обработку аллергий, штрафы, push-инфраструктуру и opt-out, напоминания, пагинацию/retention, мониторинг, SLA и очистку idempotency records.

## Критерий завершения ревью

- все найденные продуктовые решения внесены в журнал, а не скрыты в реализации;
- открытые замечания имеют этап-владельца и не объявлены выполненными;
- исходный бриф остаётся неизменным;
- после будущего изменения BR/FR/NFR выполняется impact analysis по матрице трассировки.
