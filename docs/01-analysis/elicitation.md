# Выявление требований

## Вопросы заказчику

1. Как клиент авторизуется? Для MVP принято: тестовый профиль уже авторизован.
2. За сколько часов разрешена бесплатная отмена? Для MVP принято: не позднее чем за 12 часов.
3. Сколько мест может забронировать один клиент? Для MVP: одно место на один аккаунт.
4. Нужно ли оплачивать класс онлайн? Нет, оплата на месте; платёжный шлюз вне MVP.
5. Какие аллергии нужно собирать? Свободный текст до 300 символов; клиент может указать «нет».
6. Как рассчитывается аренда? Фиксированная доплата к цене класса согласно API.
7. Когда разрешена оценка шефа? После завершения посещённого класса, один раз.
8. Нужны ли push-уведомления? В API предусматривается регистрация push-токена, но реальная доставка вне демонстрационного клиента.

## Принятые допущения

- Валюта — российский рубль.
- Время API передаётся в ISO 8601 с часовым поясом студии.
- Клиент не может иметь две активные брони одного класса.
- Прокат ограничен серверным остатком и подтверждается при бронировании.
- В демонстрационной версии API имитируется локальным репозиторием с теми же контрактами.

## Открытые вопросы перед production

- способ авторизации и восстановления доступа;
- юридический текст согласия на обработку сведений об аллергиях;
- правила штрафа за позднюю отмену;
- канал и провайдер push-уведомлений;
- аналитика и политика хранения персональных данных.
