# SCR-001 · Классы / расписание

**Тип:** top-level screen · **Приоритет:** Critical · **Истории:** US-01, US-02 · **Дизайн:** [SCR-001](../03-design-brief/SCR-001-class-schedule.md).

## Вход и выход

- Вход: запуск после инициализации dev-auth; tap таба «Классы».
- Выход: tap CMP-001 → BS-001; tap другого bottom tab → SCR-002/SCR-003.
- При возврате из BS-001 без успеха фильтры сохраняются.

## Данные и API

`listClasses(from, to)` вызывается при первом входе и смене 7/14/30. `level` применяется локально; серверный параметр остаётся допустимой оптимизацией без изменения UI. Bearer обязателен.

| Ответ | Реакция |
|---|---|
| `200 []` | Empty для выбранной комбинации |
| `200 data` | Content; применить LOGIC-001 |
| `400/422` | Error конфигурации диапазона; retry после пересборки query |
| `401` | Demo-auth error, не Empty |
| `429` | Error/Stale, retry после `Retry-After` |
| `500/503/network` | LOGIC-007: Error при первом запросе, Stale при refresh |

### CMP-001

Поля: `startsAt`, `title`, `level`, `chef.name`, `priceKopecks`, `availableSeats`, декоративные `accent/softAccent`. `availableSeats == 1` → «Последнее место»; `0` и status не `scheduled` не попадают в доступный список. Цена форматируется LOGIC-002, даты — LOGIC-001/NFR-007.

## Состояния

| State | Отображение |
|---|---|
| Loading | Фильтры + skeleton/loader списка |
| Content | CMP-001 по времени |
| Empty | «Пока нет доступных классов» + совет сменить дату/уровень |
| Error | «Не удалось загрузить расписание» + «Повторить» |
| Refreshing | Старые карточки + индикатор |
| Stale | Старые карточки + сообщение/повтор |

## Критерии приёмки

- **AC-SCR001-01:** default query и UI охватывают 7 московских календарных дней.
- **AC-SCR001-02:** смена уровня сохраняет дату и не вызывает API.
- **AC-SCR001-03:** `200 []` и 5xx визуально различаются.
- **AC-SCR001-04:** tap карточки передаёт в BS-001 точный `classId`.
