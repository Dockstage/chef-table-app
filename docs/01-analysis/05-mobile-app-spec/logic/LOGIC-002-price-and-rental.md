# LOGIC-002 · Цена и прокат

**Приоритет:** Critical · **Точки:** CMP-001, BS-001, CMP-002 · **Требования:** FR-003, FR-006, NFR-007.

## Правила

Все значения — целые копейки, валюта RUB. До создания брони BS-001 показывает preview:

```text
preview = class.priceKopecks
        + (equipmentOption == rental ? class.rentalPriceKopecks : 0)
```

После `201` и в CMP-002 единственный источник итоговой цены — серверное `Booking.totalPriceKopecks`; клиент её не пересчитывает. Это сохраняет snapshot тарифа на момент записи.

## Прокат

- `own` — доплата 0.
- `rental` доступен только при `availableRentalKits > 0`.
- Нулевой остаток делает radio disabled и показывает причину.
- `409 RENTAL_UNAVAILABLE` означает устаревший остаток: обновить класс, сохранить аллергии, предложить `own`.

## Форматирование

- Отображение: `Intl.NumberFormat('ru-RU')`, деление копеек на 100, суффикс `₽`.
- `0` валиден и отображается как «Бесплатно» либо `0 ₽` единообразно на всех точках.
- Отрицательное, fractional, missing или нечисловое значение считается ошибкой контракта: сумма `—`, create CTA disabled, доступно обновление.
- Не использовать float для сложения или хранения.

## Критерии

- Переключение own/rental немедленно и без запроса обновляет preview.
- При rental preview увеличивается ровно на `rentalPriceKopecks`.
- После создания карточка показывает серверный total, даже если тариф класса позже изменился.
