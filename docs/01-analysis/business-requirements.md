# Бизнес-требования

Бизнес-требования описывают ожидаемый результат для студии и клиента, не предписывая реализацию. Приоритет задан по MoSCoW. Канонические продуктовые границы определены в `customer-questions.md` и `decisions/ADR-001-own-backend.md`.

| ID | Бизнес-цель | Проверяемый результат MVP | Приоритет | Источник |
|---|---|---|---|---|
| BR-001 | Перевести выбор и запись на классы из переписки в самообслуживание | Клиент без обращения к сотруднику просматривает расписание, выбирает класс и получает подтверждённую бронь в приложении | Must | Бриф; Q-001; Q-017 |
| BR-002 | Исключить подтверждение недоступного места и повторные активные записи | Каждая подтверждённая бронь проходит серверную проверку; при конкурентной записи лишние брони не создаются; у клиента не более одной активной брони класса | Must | Бриф; Q-004; Q-006; BRULE-006–BRULE-009 |
| BR-003 | Сделать изменения записи понятными и сохранить историю | Допустимая отмена освобождает ресурсы, а отмена студией остаётся в истории со статусом и причиной | Must | Бриф; Q-010; Q-011; BRULE-010–BRULE-012 |
| BR-004 | Своевременно сообщать записанным клиентам об отмене класса | Клиент с включёнными уведомлениями получает событие об отмене, после которого приложение показывает актуальную бронь и причину | Must | Бриф; Q-014; BRULE-016 |
| BR-005 | Собирать обратную связь о работе шефов | После посещения клиент может один раз сохранить оценку 1–5 и необязательный комментарий | Should | Бриф; Q-013; BRULE-013 |
| BR-006 | Ограничить учебный MVP минимально необходимой клиентской поставкой | В приложении доступны только клиентские сценарии; админка, интерфейс шефа, онлайн-оплата и лояльность отсутствуют | Must | Уточнение брифа R-028; Q-001; Q-009; Q-019; D-004 |

## Метрики успеха

- 100% подтверждённых броней созданы после серверной проверки доступности.
- 0 двойных активных броней одного клиента на один класс.
- Основной сценарий занимает не более пяти действий после открытия карточки класса.
- Каждое Must-требование имеет хотя бы один тест-кейс до итоговой сдачи.
