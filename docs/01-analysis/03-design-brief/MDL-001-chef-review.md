# Требования на дизайн · MDL-001 · Оценка шефа

**Тип:** центрированный modal · **Приоритет:** Medium · **Статус:** актуально для MVP · **Baseline:** `ReviewModal`.

**Источники:** [Foundations](00-foundations.md), US-05, UC-03, FR-012, NFR-003, NFR-005.

## Назначение

Позволить клиенту один раз оценить шефа после посещения, не уводя из истории записей.

## Контент и порядок

1. Заголовок «Как вам шеф?».
2. Имя шефа и название класса как контекст.
3. Пять выбираемых звёзд с доступным названием «Оценка N из 5».
4. Необязательный комментарий и счётчик 0/500.
5. Primary CTA «Отправить оценку».
6. Вторичное действие «Не сейчас».

## Поведение

- Modal доступен только для `attended` без сохранённого отзыва.
- Оценка обязательна, целая 1–5; CTA disabled при нуле и во время отправки.
- Комментарий необязателен, максимум 500 Unicode code points; keyboard не скрывает поле и CTA.
- Close/«Не сейчас» не отправляет и не очищает серверные данные.
- После успеха modal закрывается, а оценка/комментарий постоянно видны в CMP-002.

## Состояния и ошибки

| Состояние | Представление |
|---|---|
| Initial | Ни одна звезда не выбрана, CTA disabled |
| Ready | Выбранная оценка объявляется и видна без одного цвета |
| Submitting | Progress на CTA, повторный tap заблокирован |
| `REVIEW_NOT_ALLOWED` | Сообщить, что отзыв уже сохранён/недоступен; обновить карточку |
| Offline/5xx | Modal остаётся, ввод сохраняется, доступен повтор |

## Критерии для макета

- Каждая звезда имеет зону не меньше 44×44 dp и отдельный accessibility label.
- Длинные имя/название и увеличенный текст не вытесняют действия за экран.
- Предусмотрены initial, selected, submitting и error состояния.
