# Требования на дизайн · BS-001 · Детали класса и запись

**Тип:** bottom sheet · **Приоритет:** Critical · **Статус:** актуально для MVP · **Baseline:** `ClassModal`.

**Источники:** [Foundations](00-foundations.md), US-02, US-03, UC-01, FR-003, FR-005–FR-008, NFR-004, NFR-006, NFR-007, NFR-012.

## Назначение

Объединить принятие решения и оформление одного места без лишнего экрана: показать подробности, собрать выбор набора и необязательные аллергии, объяснить итог и отправить бронь.

## Навигация

- Вход: tap по CMP-001 на SCR-001.
- Close/back: возврат на SCR-001 без запроса.
- Успех `201`: закрыть sheet, открыть SCR-002 → «Предстоящие» и показать постоянную карточку результата.
- Ошибка: sheet остаётся открыт; безопасный ввод сохраняется.

## Иерархия

1. Handle, заголовок класса, close 44×44 dp, краткое описание.
2. Дата/время, длительность, уровень, адрес, шеф, свободные места.
3. Меню/блюда.
4. Radio-карточки «Возьму свой» и «Нужен набор» с доплатой и остатком.
5. Многострочное поле «Аллергии», счётчик 0/300 и privacy-подсказка.
6. Разбивка: цена класса, доплата проката при выборе, итог; «Оплата в студии».
7. Primary CTA «Записаться на класс» и правило отмены за 12 часов.

## Поведение и валидация

- Бронируется ровно одно место. Default — собственный набор.
- Прокат disabled при нулевом остатке с текстом «Нет свободных наборов»; причина не скрывается.
- Аллергии необязательны. До 300 Unicode code points — валидно; при 301 CTA недоступен, счётчик и inline-текст сообщают лимит.
- Итоговое превью считается в целых копейках: `priceKopecks + rentalPriceKopecks` только для rental.
- При отправке CTA показывает progress и блокирует повторный tap; одна логическая попытка не должна выглядеть как две записи.

## Состояния ответа

| Результат | Реакция дизайна |
|---|---|
| `201` | Переход к SCR-002; успешная бронь видна постоянно, toast только дополняет результат |
| `409 SLOT_FULL` | «Место уже заняли»; актуализировать остаток; сохранить выбор/аллергии, если повтор ещё возможен |
| `409 RENTAL_UNAVAILABLE` | Обновить остаток; предложить «Возьму свой», не сбрасывать аллергии |
| `409 DUPLICATE_BOOKING` | Объяснить наличие записи и дать путь в SCR-002 |
| `410 SLOT_CANCELLED` | Запретить CTA, показать отмену/причину и путь назад |
| Timeout/offline/5xx | Не показывать успех; сохранить форму и дать повтор той же логической попытки |

## Edge cases

- Цена `0` — валидное «Бесплатно», не отсутствие данных.
- Отрицательная/отсутствующая цена или дата — ошибка данных: CTA заблокирован, доступно обновление.
- Длинные меню и описание скроллятся; CTA/активное поле не перекрываются клавиатурой.
- Аллергии не повторяются в toast, error и экране истории.

## Критерии для макета

- На любом шаге понятно, какой класс и какую сумму подтверждает клиент.
- Own/rental различимы текстом и selected state, не только цветом.
- Отрисованы Content, submitting и все четыре предметных конфликта.
- Close, keyboard и длинный контент проверены на 360×800.
