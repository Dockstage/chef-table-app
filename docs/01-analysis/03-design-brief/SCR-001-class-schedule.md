# Требования на дизайн · SCR-001 · Классы

**Тип:** верхнеуровневый экран · **Приоритет:** Critical · **Статус:** актуально для MVP · **Baseline:** `DiscoverScreen`.

**Источники:** [Foundations](00-foundations.md), US-01, US-02, FR-001–FR-004, NFR-001–NFR-003.

## Назначение

Дать клиенту быстро выбрать период, дату и уровень, сравнить доступные классы и открыть детали. Экран стартовый и не требует предварительных действий пользователя.

## Навигация

- Вход: запуск приложения или таб «Классы».
- Тап по CMP-001 открывает [BS-001](BS-001-class-booking.md).
- Смена таба сохраняет выбранные период, дату и уровень в рамках сессии.

## Иерархия

1. Хедер «Что приготовим?» и компактный атмосферный intro-блок.
2. Сегмент периода: 7 / 14 / 30 дней; default — 7.
3. Горизонтальная лента дат с выбранным днём.
4. Заголовок «Классы», число результатов и сегмент уровня: все / новичкам / с опытом.
5. Список CMP-001 либо состояние Loading/Empty/Error.
6. Нижняя навигация.

## CMP-001 — Карточка класса

Карточка целиком кликабельна и показывает: дату/время, название, уровень, шефа, цену за одно место и остаток мест. При одном месте нужен текстовый акцент «Последнее место». Отменённые/завершённые классы не показываются как доступные для записи. Декоративный цвет класса не используется как единственный носитель смысла.

## Состояния и поведение

| Состояние | Требование к дизайну |
|---|---|
| Loading | Сохраняется каркас фильтров; список заменён 2–3 скелетонами либо явным индикатором |
| Content | Карточки отсортированы по началу, выбранные фильтры и число результатов видимы |
| Empty | «Пока нет доступных классов» + совет выбрать другой день/уровень |
| Error | Сообщение «Не удалось загрузить расписание» + «Повторить»; empty state не используется |
| Refresh error | Старые карточки остаются, появляется ненавязчивое сообщение |

- Смена 7/14/30 может вызвать loading списка, но не должна сбрасывать уровень без причины.
- Если выбранная дата исчезла из нового диапазона, выбирается первый день и изменение очевидно пользователю.
- Горизонтальная прокрутка дат не вызывает горизонтальный overflow всей страницы.

## Критерии для макета

- На 360×800 видны выбранная дата, фильтр уровня и начало хотя бы одной карточки либо состояние списка.
- Период, дата и уровень визуально различаются как три разных уровня фильтрации.
- Цена, время и остаток читаются без открытия sheet.
- Предусмотрены Content, Loading, Empty, Error и «последнее место».
