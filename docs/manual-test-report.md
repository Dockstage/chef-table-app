## Ограничение внешней среды

End-to-end доставка реального APNs/FCM push не может быть выполнена без физического устройства, production-ключей и адреса существующего backend. Клиентская часть сценария реализована полностью; инструкции для интеграционной проверки находятся в `docs/tasks/TASK-011-push-cancellations.md`.
