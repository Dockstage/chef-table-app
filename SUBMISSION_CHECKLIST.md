## Нужно сделать владельцу репозитория

1. При необходимости заменить тестовые имя и телефон в `App.tsx`.
2. Указать своё имя в Git-коммитах будущих изменений.
3. Создать новый пустой репозиторий на GitHub, не добавляя README или `.gitignore` через сайт.
4. Выполнить из папки проекта:

   ```bash
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```

5. Открыть репозиторий в режиме инкогнито и убедиться, что он доступен проверяющим.
6. В форму задания вставить ссылку на репозиторий и перечислить инструменты: Codex, Expo, React Native, TypeScript, Vitest.

Перед отправкой ещё раз выполнить:

```bash
npm ci
npm run typecheck
npm test
npm run export:web
git status
```

`git status` должен показать чистую рабочую ветку.
