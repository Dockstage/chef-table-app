## Перед отправкой формы

1. Открыть [репозиторий](https://github.com/Dockstage/chef-table-app) в режиме инкогнито и убедиться, что он доступен проверяющим.
2. В форму задания вставить ссылку на репозиторий.
3. В инструментах указать: Codex, Expo, React Native, TypeScript, Vitest, Expo Notifications.
4. При необходимости заменить демонстрационные имя и телефон в `App.tsx` — на оценивание функций это не влияет.

Перед отправкой ещё раз выполнить:

```bash
npm ci
npm run typecheck
npm test
npm run export:web
git status
```

`git status` должен показать чистую рабочую ветку.
